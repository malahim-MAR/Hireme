# Hireme — ThinkBoard Application Pipeline Tracker

A full-stack MERN application to track and manage job applications across every stage: Applied, Interviewing, Offer Received, and Rejected.

## Features
- **Status-Driven Pipeline**: Track job applications with dedicated stage color-coding.
- **Search & Filter**: Real-time filtering by stage, company, job title, and keywords.
- **Full-Stack MERN**: Express.js REST API with MongoDB & Mongoose backend, React 19 + Vite 7 frontend.
- **Interactive Management**: Quick status switcher, expandable cover letter excerpts, and responsive UI.

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
